任务一·提示词工程师 · 容器 #wySw4 · ① 无缝循环 ② 3.2s 自动翻页不停 ③ 圆点可点击 ④ cube 效果

第 1 张手动拖动试试：松手后自动播放不停止（需求②）
第 2 张点击下方圆点可直接跳转（需求③）
第 3 张当前切换动画是立体翻转 = cube（需求④）
第 4 张末张继续向后滑 → 无缝接回第 1 张（需求①）
第 5 张每 3.2 秒自动翻一张（需求②）

验证清单（截图 + 一句话结论，对照填写）

  • ① 无缝循环：滑到最后一张继续向后滑，直接接回第 1 张，无空白断层。
  • ② 3.2 秒自动翻页且手动操作后不停止：手动拖一次再等待，约 3.2 秒后仍在自动翻页。
  • ③ 圆点分页器可点击：点击第 3 个圆点，直接跳到第 3 张。
  • ④ 初始效果为 cube：切换动画为立体翻转，而非水平平移。
new Swiper('#wySw4', { loop: true, // ① 无缝循环 autoplay: { // ② 自动翻页 delay: 3200, // 3.2 秒/次 disableOnInteraction: false, // 手动操作后不停止（关键项） }, pagination: { // ③ 圆点分页器 el: '.swiper-pagination', clickable: true, // 可点击跳转 }, effect: 'cube', // ④ 立方体效果 cubeEffect: { // cube 外观参数（增强立体观感，非必需） slideShadows: true, shadow: true, shadowOffset: 100, shadowScale: 0.6, }, });
