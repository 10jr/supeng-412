超纲能力为什么选 keyboard 任务三 ②

为什么选它

课堂讲了 loop / autoplay / effect / pagination / navigation，keyboard 完全没提。 代码只有一行配置，但答辩时能讲清「焦点、容器、边界」三件事，性价比最高。

怎么加

初始化时加 keyboard: { enabled: true, onlyInViewport: true }。 第二个参数保证只有轮播在可视区域内才响应按键，避免用户滚到别处时方向键被「偷走」。

踩到的坑

第一版没加 onlyInViewport，又在页面顶部放了个输入框测试， 结果打字时光标一动轮播就翻页——按键被全局抢走了。

new Swiper('#spSwShow', {
  loop: true,
  effect: 'slide',
  speed: 650,
  keyboard: {
    enabled: true,
    onlyInViewport: true   // 只在轮播可见时接管方向键
  },
  autoplay: { delay: 4000, disableOnInteraction: false },
  pagination: { el: '#spPagShow', clickable: true },
  navigation: { nextEl: '#spNextShow', prevEl: '#spPrevShow' },
  // 每次切换后把「第几件展品」写回提示条
  on: {
    slideChange: function () {
      var sp_i = this.realIndex + 1;
      document.getElementById('sp_state').textContent =
        '当前第 ' + sp_i + ' / 6 件展品';
    }
  }
});

我要给「大国重器光影展」加第六件展品：爱达·魔都号，首艘国产大型邮轮，2024 年 1 月首航。 请给我一段可以直接用于文生图模型的英文提示词，要求横版 16:9、写实摄影风格、 船体有彩色涂装、背景是上海外滩天际线、黄昏暖光。

答辩四连问 准备答案

1. 这段代码什么意思？

初始化六件展品的轮播：loop 循环、autoplay 每 4 秒自动翻、分页器和左右箭头、keyboard 接管方向键， on.slideChange 在每次切换后把 realIndex 写进提示条，让观众知道现在是第几件。

2. AI 第一次给的哪里不对、你改了什么？

图片提示词漏了比例和地标，生成图是竖版、无上海背景；keyboard 那版没提 onlyInViewport， 导致输入框打字时轮播跟着翻。两处都是「漏了约束」，不是语法错。

3. 新参数的作用？

keyboard.enabled 开启方向键控制；onlyInViewport 限定只有轮播在视口内才响应， 防止抢走页面其他区域的按键；realIndex 是去掉 loop 复制片后的真实下标，用它算序号才不会错。

4. 现场把 delay 改成指定值，预期会怎样？

比如改成 1500：每张只停 1.5 秒，翻页明显变快；改完要重新初始化才生效， 或者直接改 sp_swiperShow.params.autoplay.delay = 1500 后调用 autoplay.start() 立即生效。
