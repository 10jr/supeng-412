creative 的核心配置 任务二代码

new Swiper('#spSwEff', {
  loop: true,
  effect: 'creative',
  speed: 700,
  creativeEffect: {
    // prev：已经滑过去的那一张 —— 缩小、左移、带一点角度
    prev: {
      translate: ['-30%', 0, -500],
      rotate: [0, 0, -12],
      scale: 0.85,
      opacity: 0.45,
      shadow: true
    },
    // next：还没进来的那一张 —— 从右侧放大推进场
    next: {
      translate: ['110%', 0, 120],
      rotate: [0, 0, 4],
      scale: 1.04,
      opacity: 1
    }
  },
  autoplay: { delay: 3200, disableOnInteraction: false },
  pagination: { el: '#spPagEff', clickable: true },
  navigation: { nextEl: '#spNextEff', prevEl: '#spPrevEff' }
});

我的理解 用自己的话写下

prev 的 transform 控制什么？

控制「已经看过的上一张」去哪、变成什么样。我让它向左平移 30%、往画面深处退 500px、 缩小到 0.85、左倾 12 度、半透明——像电影选片墙里被推到侧边、稍微失焦的旧海报。

next 的 transform 控制什么？

控制「即将进场的那一张」从哪来、怎么来。我让它从右侧 110% 处、放大 1.04 倍、 微微右倾 4 度推进来——像新海报被推到眼前，主角感更强。

translate 的数组是什么顺序？

  • 第 1 位：X 轴（左右）
  • 第 2 位：Y 轴（上下）
  • 第 3 位：Z 轴（远近，负值后退）

百分号相对谁？

相对 slide 自己的宽高，不是容器。'-30%' 表示往左挪自身宽度的 30%， 所以换图片尺寸时位置关系依然成立，不用改数字。

答辩抽问 能现场改才算会

transform 里的百分号是相对谁的？

相对 slide 自身的宽高。改容器宽度时，-30% 仍是自身宽度的 30%，比例不变。

改一个数值让卡片转 20 度，怎么改？

把 prev 的 rotate: [0, 0, -12] 改成 rotate: [0, 0, -20] （或 next 的 4 改成 20）。第三个值是 Z 轴旋转，也就是平面内的顺时针/逆时针转，负值向左倾。

为什么切换效果时要销毁重建实例？

effect 及其配套参数（cubeEffect / coverflowEffect / creativeEffect）只在初始化时读取， 运行中直接改 params 不会重建对应样式。所以本页用 destroy(true, true) 后重新 new，最稳。
