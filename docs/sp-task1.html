需求拆解 写提示词前先拆

① 无缝循环

最后一张往后翻要回到第一张，不能到头卡住 → loop: true

② 3.2 秒自动翻页，手动后不停

默认交互后会自动停止，必须显式关掉 → disableOnInteraction: false

③ 圆点分页器可点击

只写 el 只是显示圆点，点不动 → 还要 clickable: true

④ 初始效果 cube

要 3D 立方体，同时把切换时长调到 800ms 才有立体感 → effect: 'cube'

第 1 轮提示词 AI 答案有漏项

提示词 v1漏 2 项

我的原始提示词
用 Swiper 11 给 id 为 spSw4 的轮播写初始化配置：要循环播放，每 3.2 秒自动翻页， 底部有圆点分页器，效果用 cube。
AI 第 1 轮回答
new Swiper('#spSw4', {
  loop: true,
  autoplay: { delay: 3200 },          // 问题1：没写 disableOnInteraction
  pagination: { el: '#spPag4' },        // 问题2：没写 clickable
  effect: 'cube'
});
我当时的判断
代码能跑，肉眼看着也「像那么回事」，但一动手就露馅：拖一下轮播，自动播放就停了； 圆点亮着却点不动。这两条正是被 AI 悄悄省略的细节。

提示词 v2四项全中

我的第二轮提示词（把隐式要求写成显式约束）
上一版有两个问题：用户手动拖动后自动播放停了，圆点也点不动。 请修改：① autoplay 里加 disableOnInteraction: false，保证手动操作后继续自动翻； ② pagination 加 clickable: true，让圆点可点击跳转； ③ 保留 loop:true 和 effect:'cube'；④ 另外把切换速度设成 800ms，让立方体转动更明显。 只给配置对象，不要多余解释。
AI 第 2 轮回答（最终采用）
new Swiper('#spSw4', {
  loop: true,
  effect: 'cube',
  speed: 800,
  cubeEffect: { shadow: true, slideShadows: true },
  autoplay: {
    delay: 3200,
    disableOnInteraction: false
  },
  pagination: { el: '#spPag4', clickable: true }
});

答辩抽问 先想再看

第一版提示词漏掉了哪个需求？

漏的是两个「隐性默认值」：autoplay 的 disableOnInteraction 和 pagination 的 clickable。 它们都有默认值，所以不写也不报错，但行为跟需求相反——这正是提示词要写清约束的原因。

第二轮是怎么「说清楚」的？

不再描述目的（「手动后不停」），而是直接给出参数名和取值（disableOnInteraction: false）， 并点名上一版的具体故障现象。目的描述容易被自由发挥，参数约束不会。

AI 第一次给的代码错在哪？

不是语法错，是「语义错」：能跑、能看，但自动播放会被交互打断、圆点点了没反应。 所以 AI 代码必须逐条对照需求做行为验证，而不是只看有没有报错。
