任务一 · 提示词工程师：让 AI 听懂需求

第 1 轮提示词（新手版）

帮我写一个 Swiper 轮播图配置，容器是 #wySw4，要能自动播放，谢谢。

第 1 轮 AI 回答

new Swiper('#wySw4', { autoplay: 3000, loop: true, });
  • 错误①：autoplay: 3000 —— 间隔错（3000 ≠ 3.2 秒），且是旧版数字写法，新版应为对象形式
  • 错误②：缺 disableOnInteraction: false —— 用户手动一拖动，自动播放就停止
  • 错误③：分页器配置整体缺失 —— 圆点不会出现，更谈不上可点击
  • 错误④：缺 effect: 'cube' —— 默认是 slide 平移效果

第 2 轮提示词（精确拆解版）

请生成 new Swiper('#wySw4', {...}) 完整配置，使用新版 Swiper 语法，严格满足以下 4 项需求并在每个配置项后加注释标明对应第几条：① 无缝循环播放；② 每 3.2 秒自动翻页，且用户手动拖动/点击后自动播放不停止（注意 disableOnInteraction 参数）；③ 圆点分页器且可点击跳转；④ 切换效果为 cube（立方体）。最后逐条说明每项需求对应哪个配置项。

第 2 轮 AI 回答（正确答案）

new Swiper('#wySw4', { loop: true, // ① 无缝循环 autoplay: { // ② 自动翻页 delay: 3200, // 3.2 秒/次 disableOnInteraction: false, // 手动操作后不停止（关键项） }, pagination: { el: '.swiper-pagination', clickable: true }, // ③ 圆点可点击 effect: 'cube', // ④ 立方体效果 });

亲自验证结论（截图实测）

  • ① 无缝循环：末张后无缝接回首张，无空白断层 ✅
  • ② 3.2 秒自动翻页：手动拖一次后仍在约 3.2 秒继续自动翻页 ✅
  • ③ 圆点可点击：点击第 3 个圆点直接跳到第 3 张 ✅
  • ④ 初始效果 cube：切换动画为立体翻转而非水平平移 ✅

爱达·魔都号

首艘国产大型邮轮 · 2024 年 1 月首航（任务三新增展品）

追问：prev / next 的 transform 各控制什么？（我自己的话）

prev 的 transform 控制"即将退场的上一张"的去向：往哪边退（translate 的 x 是 -85%，即左移 85% 自身宽度）、退得多远所以显得多小（z 是 -320px，被推远就变小）、退的时候歪多少度（rotate 第三个值 -14，向左倾 14 度）、退场后还剩多亮（opacity 0.4）。

next 的 transform 控制"即将进场的下一张"的来路：从右边来（x 是 85%）、离镜头比上一张近所以看起来是"放大"进场（z 是 -120px，比 prev 的 -320 近）、歪 12 度进场（rotate 12）、亮度 0.7。

一句话总结：prev 管"退场时的姿态"，next 管"进场时的姿态"。两个都写好，左边斜着缩进去的是看过的海报，右边微微放大等着你选的是下一张——这就是电影选片墙的观感。

答辩知识点①：transform 里的百分号是相对 slide 自身尺寸的——x% 相对自身宽度，y% 相对自身高度，z 轴是像素距离；rotate 单位是度（deg）。
答辩知识点②：想把卡片转到 20 度，把 creativeEffect 里 rotate 的第三个值从 -14 改成 -20（或 20）即可。
